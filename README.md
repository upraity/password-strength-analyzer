# Password Strength Analyzer

A small, privacy-first web tool that analyzes password strength locally in the browser.

## Project Information

- Type: Mini
- Difficulty: Beginner
- Category: Cyber Security
- Technology: HTML, CSS, JavaScript

## Features

- Real-time strength scoring
- Length and character-variety checks
- Lowercase, uppercase, number and special-character checks
- Common-password and simple-pattern detection
- Improvement suggestions
- Responsive interface
- No server
- No API
- No database
- No network request for password analysis
- Password is processed locally by JavaScript

## Run

No installation is required.

1. Extract the ZIP.
2. Open the project folder.
3. Double-click `index.html`, or double-click `run.bat`.
4. The application opens in your browser.

## Privacy

The password is analyzed in the browser. The application does not send it to a server or store it in a database.

## Security Notice

This project is an educational password-strength estimator. A score is not a guarantee that a password is secure or resistant to every attack. Do not treat the tool as a password manager, breach checker, authentication system, or cryptographic password-strength proof.

For important accounts, use a reputable password manager and unique passwords.
